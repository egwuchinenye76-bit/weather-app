# 🌤️ Weather App

A clean and responsive weather application that provides real-time weather data for any city using the OpenWeather API.

🔗 **Live Demo:** https://egwuchinenye76-bit.github.io/weather-app/

---

## ✨ Features

* 🔍 Search weather by city name
* 🌡️ Real-time temperature display
* 💧 Humidity and wind speed
* 🌥️ Dynamic weather icons
* 🎨 Background changes based on weather
* 📱 Fully responsive design

---

## 🛠️ Tech Stack

* HTML
* CSS
* JavaScript
* OpenWeather API

## 🚀 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/egwuchinenye76-bit/weather-app.git
```

2. Open the project folder

3. Replace the API key in `script.js`:

```javascript
const apiKey = "YOUR_API_KEY";
```

4. Open `index.html` in your browser

---

## ⚠️ Note

This project uses the OpenWeather API.
You need your own API key to run it locally.
